# CADICA 협착 탐지·분류 — 아키텍처 & 흐름도

> 근거: (2팀)연구계획서(수정완료)  
> 과제: 설명가능한 딥러닝 기반 관상동맥 혈관조영술 협착 탐지 및 중증도 분류

---

## 1. 전체 시스템 아키텍처 (한눈에)

```mermaid
flowchart TB
    subgraph DATA["① 데이터"]
        A[CADICA Dataset<br/>42 patients / selected videos]
        A --> B[LCA/RCA 334 videos<br/>view 미분류 48 제외]
        B --> C1[분류용 keyframe<br/>5,305장]
        B --> C2[탐지용 bbox frame<br/>3,685장]
        B --> S[common_split.csv<br/>patient 단위 80/10/10]
    end

    subgraph PRE["② 전처리"]
        C1 --> P1[resize per model<br/>224 / 299 / 380]
        C2 --> P2[YOLO format<br/>imgsz 640+]
        P1 --> AUG[정규화 + Augmentation]
        P2 --> AUG2[원본 + framework aug]
        AUG -.->|선택 ablation| CLAHE[CLAHE]
    end

    subgraph CLS["③ 분류 Classification"]
        AUG --> G1[Group1 ConvNeXt-T/S]
        AUG --> G2c[Group2 Swin-T]
        AUG --> G3[Group3 MobileNetV2 / Eff-B0]
        AUG --> G4[Group4 Inception-V3 / Eff-B4]
        G1 & G2c & G3 & G4 --> COUT[lesion / non-lesion<br/>+ 확장: 중증도]
    end

    subgraph DET["④ 탐지 Detection"]
        AUG2 --> G5[Group5 YOLOv4 / YOLOv8]
        AUG2 --> G2d[Group2 RT-DETR]
        G5 & G2d --> DOUT[Bounding Box<br/>mAP50 / mAP50-95]
    end

    subgraph XAI["⑤⑥ 설명·불확실성 (추가)"]
        COUT --> CAM[Grad-CAM]
        DOUT --> IOU[CAM ↔ BBox 일치 검토]
        COUT --> MC[MC Dropout / ECE]
    end

    subgraph EVAL["⑦ 평가"]
        COUT --> M1[F1 / Bal Acc / ROC-AUC]
        DOUT --> M2[mAP / P / R]
        G3 --> M3[Inference ms / Params]
    end

    subgraph SERVE["⑧ 서빙 (추가)"]
        M1 & M2 --> API[REST API Prototype]
        API --> CDSS[CDSS Dashboard 연계 검토]
    end
```

## 3. 전처리 분기 흐름도

```mermaid
flowchart TB
    IN[Keyframe / BBox Frame] --> RESIZE{모델별 resize}

    RESIZE -->|분류 224| R224[ConvNeXt / Swin / MobileNet / Eff-B0]
    RESIZE -->|분류 299| R299[Inception-V3]
    RESIZE -->|분류 380| R380[EfficientNet-B4]
    RESIZE -->|탐지 640+| R640[YOLO / RT-DETR]

    R224 & R299 & R380 --> NORM[Normalize]
    NORM --> AUG[Augmentation<br/>rotate / translate / scale]
    AUG --> OPT{CLAHE ablation?}
    OPT -->|ON| CL[CLAHE 적용]
    OPT -->|OFF| RAW2[원본 유지]
    CL --> CLS_IN[Classification Input]
    RAW2 --> CLS_IN

    R640 --> YOLOFMT[YOLO label format<br/>class cx cy w h]
    YOLOFMT --> FAUG[Framework default aug]
    FAUG --> DET_IN[Detection Input]
```

## 6. 추론 시 임상 보조 흐름 (목표 아키텍처)

```mermaid
flowchart TB
    IMG[ICA Frame 입력] --> PRE[전처리]

    PRE --> DET[탐지 모델 Best<br/>YOLO or RT-DETR]
    PRE --> CLS[분류 모델 Best<br/>경량 or 고성능]

    DET --> BOX[Bounding Box<br/>+ confidence]
    CLS --> LAB[lesion / non-lesion<br/>+ probability]

    LAB --> CAM[Grad-CAM heatmap]
    BOX --> OVERLAY[시각화 오버레이]
    CAM --> OVERLAY

    LAB --> UNC{불확실성 높음?}
    UNC -->|Yes| REJ[판독 보류 Reject]
    UNC -->|No| OK[결과 제시]

    OVERLAY --> UI[CDSS Dashboard]
    OK --> UI
    REJ --> UI
```

## 8. 연구가설 ↔ 실험 매핑

| 가설 | 비교 대상 | 핵심 지표 |
|------|-----------|-----------|
| H1 탐지 고도화 | YOLOv4 vs YOLOv8 vs RT-DETR | mAP50, mAP50-95, Recall |
| H2 성능–속도 트레이드오프 | G3(경량) vs G4(고성능) + ConvNeXt/Swin | F1, Bal Acc, ms, params |
| H3 불확실성 제어 | MC Dropout ×20 | ECE, Reject 가능성 |
